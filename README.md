# Iframe Assignments

This branch contains all my HTML assignments and exercises related to **iframes**.  
The purpose is to practice embedding HTML pages within other pages using `<iframe>` and `<frameset>`.

## Contents

- `assignment1.html` – Basic iframe example with one embedded page.  
- `assignment2.html` – Two iframes stacked vertically.  
- `nav.html` – Navigation page for iframe examples.  
- `welcome.html` – Content page for iframe examples.  
- `frameset-example.html` – Example using `<frameset>` for top navigation and bottom content.

## How to View

1. Clone the repository or switch to the `iframe` branch.  
2. Open any `.html` file in a web browser.  
3. For navigation examples, click the links to see content load in the target frame.

## Notes

- All examples are in **HTML only**, no CSS or JavaScript is used unless specified.  
- `<frameset>` is **deprecated in HTML5**, but used here for practice and understanding legacy HTML.
